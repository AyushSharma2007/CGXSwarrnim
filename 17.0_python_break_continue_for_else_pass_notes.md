# 1. The `break` Statement

## 1.1 What is `break`?

The `break` statement immediately terminates the **nearest enclosing
loop**. Once Python executes `break`, it leaves that loop and continues
with the statement immediately after the loop.

Think of searching for a particular book on a shelf: once you find the
book, you stop searching.

## 1.2 Syntax

``` python
for variable in sequence:
    if condition:
        break
```

The same idea works with a `while` loop.

## 1.3 Example: Stop at a Number

``` python
for number in range(1, 8):
    if number == 5:
        break
    print(number)

print("Loop ended")
```

**Output:**

``` text
1
2
3
4
Loop ended
```

**Explanation:** When `number` becomes `5`, the condition is true.
`break` terminates the loop, so `5`, `6`, and `7` are not printed.

## 1.4 Example: Search for a Name

``` python
names = ["Aman", "Riya", "Kabir", "Neha"]

for name in names:
    print("Checking:", name)
    if name == "Kabir":
        print("Name found")
        break
```

**Output:**

``` text
Checking: Aman
Checking: Riya
Checking: Kabir
Name found
```

The loop stops as soon as `"Kabir"` is found.

## 1.5 `break` in a `while` Loop

``` python
number = 1

while number <= 5:
    print(number)
    if number == 3:
        break
    number += 1

print("Finished")
```

**Output:**

``` text
1
2
3
Finished
```

Notice that `number += 1` does not run when `number` is `3`, because
`break` exits the loop first.

## 1.6 Important Points

-   `break` exits only the **nearest enclosing loop**.
-   Statements after the loop can still execute.
-   If loops are nested, `break` exits the inner loop in which it
    appears; it does not automatically exit every outer loop.
-   In a loop with `else`, executing `break` prevents that loop's `else`
    block from running.

# 2. The `continue` Statement

## 2.1 What is `continue`?

The `continue` statement skips the remaining statements in the **current
iteration** and moves to the next iteration of the loop.

Think of checking a list of student records and skipping records that
should not be processed.

## 2.2 Syntax

``` python
for variable in sequence:
    if condition:
        continue
    # Remaining statements
```

## 2.3 Example: Skip Number 3

``` python
for number in range(1, 6):
    if number == 3:
        continue
    print(number)
```

**Output:**

``` text
1
2
4
5
```

**Explanation:** When `number` is `3`, Python skips `print(number)` for
that iteration. The loop then continues with `4`.

## 2.4 Example: Print Only Non-Vowel Characters

``` python
word = "education"

for character in word:
    if character in "aeiou":
        continue
    print(character)
```

**Output:**

``` text
d
c
t
n
```

**Explanation:** Each vowel is skipped. Only the consonants are printed,
one per line.

## 2.5 `continue` in a `while` Loop: Be Careful

When using `continue` in a `while` loop, make sure the loop variable
still gets updated on every required path. Otherwise, the loop may never
end.

**Incorrect example --- do not run:**

``` python
number = 0

while number < 5:
    if number == 2:
        continue
    print(number)
    number += 1
```

When `number` reaches `2`, `continue` runs before `number += 1`. The
value stays `2`, so the loop repeats forever.

**Correct version:**

``` python
number = 0

while number < 5:
    if number == 2:
        number += 1
        continue
    print(number)
    number += 1
```

**Output:**

``` text
0
1
3
4
```

## 2.6 Important Points

-   `continue` does **not** terminate the entire loop.
-   It skips only the rest of the current iteration.
-   The loop proceeds with its next iteration.
-   In a `while` loop, update the loop variable before `continue` when
    necessary to avoid an infinite loop.

# 3. The `for-else` Statement

## 3.1 What is `for-else`?

Python allows an `else` block to be attached to a `for` loop. The `else`
block runs when the loop finishes **normally**, without being terminated
by `break`.

The `else` block does not mean "the condition was false" in the same way
as an `if-else`. It is associated with the loop's completion.

## 3.2 Syntax

``` python
for variable in sequence:
    if condition:
        break
else:
    # Runs if the loop finishes without break
```

**Indentation matters:** The `else` must line up with `for`, not with
the statements inside the loop.

## 3.3 Example: Loop Completes Normally

``` python
for number in range(1, 4):
    print(number)
else:
    print("Loop completed normally")
```

**Output:**

``` text
1
2
3
Loop completed normally
```

The loop processes every value and finishes without `break`, so the
`else` block runs.

## 3.4 Example: Loop Ends with `break`

``` python
for number in range(1, 6):
    if number == 3:
        print("Stopping the loop")
        break
    print(number)
else:
    print("Loop completed normally")
```

**Output:**

``` text
1
2
Stopping the loop
```

The loop is terminated by `break`, so its `else` block is skipped.

## 3.5 Real-Life Example: Searching for a Student

``` python
students = ["Aman", "Riya", "Kabir", "Neha"]
target = "Mohan"

for student in students:
    if student == target:
        print("Student found")
        break
else:
    print("Student not found")
```

**Output:**

``` text
Student not found
```

Because `"Mohan"` is not in the list, the loop completes without
`break`, and `else` runs.

If `target = "Kabir"`, the output is:

``` text
Student found
```

The loop finds the student and executes `break`, so the `else` block
does not run.

## 3.6 What If the Sequence Is Empty?

``` python
for number in []:
    print(number)
else:
    print("No values were processed")
```

**Output:**

``` text
No values were processed
```

An empty sequence means the loop has no iterations. It finishes
normally, so `else` runs.

## 3.7 Does `for-else` Run After `continue`?

Yes. `continue` skips an iteration but does not terminate the loop with
`break`.

``` python
for number in range(1, 4):
    if number == 2:
        continue
    print(number)
else:
    print("Loop completed normally")
```

**Output:**

``` text
1
3
Loop completed normally
```

The loop finishes without `break`, so `else` runs.

## 3.8 Rules to Remember

-   Loop finishes normally → `else` runs.
-   Loop has zero iterations → `else` runs.
-   Loop executes `continue` but no `break` → `else` runs if the loop
    later finishes normally.
-   Loop executes `break` → `else` does not run.
-   An exception or an external termination does not count as normal
    completion.

# 4. The `pass` Statement

## 4.1 What is `pass`?

The `pass` statement does nothing. It is a placeholder that allows
Python code to remain syntactically valid when a statement is required
but has not been written yet.

Think of it as writing "work to be added later" in a section of a
program.

## 4.2 Syntax

``` python
pass
```

## 4.3 Example: An Empty Conditional Block

Python requires an indented statement after `if`. Use `pass` when the
block is intentionally left empty for now.

``` python
marks = 75

if marks >= 40:
    pass

print("Result checked")
```

**Output:**

``` text
Result checked
```

The `if` condition is true, but its block does nothing because it
contains only `pass`.

## 4.4 Example: An Incomplete Loop

``` python
for number in range(1, 4):
    pass

print("Loop finished")
```

**Output:**

``` text
Loop finished
```

The loop iterates, but no action is performed inside it.

## 4.5 Example: Planning a Function

``` python
def calculate_result():
    pass

print("Program started")
```

**Output:**

``` text
Program started
```

`pass` allows the function to be defined before its implementation is
ready.

## 4.6 `pass` Is Not the Same as `continue`

``` python
for number in range(1, 4):
    if number == 2:
        pass
    print(number)
```

**Output:**

``` text
1
2
3
```

`pass` does nothing, then execution continues with the next statement in
the same iteration. Therefore, `2` is printed.

Compare with `continue`:

``` python
for number in range(1, 4):
    if number == 2:
        continue
    print(number)
```

**Output:**

``` text
1
3
```

Here, `continue` skips the `print()` statement for `2`.

## One-Line Memory Trick

-   **`break`** = Stop the loop.
-   **`continue`** = Skip this iteration.
-   **`for-else`** = Run `else` if the loop finishes without `break`.
-   **`pass`** = Do nothing.

# 6. Common Mistakes

## Mistake 1: Expecting `break` to skip only one value

``` python
for number in range(1, 6):
    if number == 3:
        break
    print(number)
```

Output: `1`, `2` --- the loop stops completely at `3`.

## Mistake 2: Expecting `continue` to stop the loop

`continue` skips only the current iteration. The next iteration still
happens.

## Mistake 3: Indenting `else` incorrectly in `for-else`

Correct:

``` python
for number in range(3):
    print(number)
else:
    print("Done")
```

Incorrect indentation can make `else` belong to a different statement or
cause a syntax error.

## Mistake 4: Thinking `for-else` means the loop ran zero times

It can run after zero iterations, but it also runs after one or more
iterations if the loop finishes without `break`.

## Mistake 5: Thinking `pass` skips an iteration

`pass` does not skip anything. Use `continue` if the remaining
statements in the current iteration must be skipped.
