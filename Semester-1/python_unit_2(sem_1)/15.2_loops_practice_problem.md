# Python For Loop — Progressive Practice Problems

## Objective

This practice set is designed to help students apply the `for` loop with previously learned Python concepts.

### Topics Used

- Variables
- Data Types
- Type Casting
- Arithmetic Operators
- Assignment Operators
- Comparison Operators
- Boolean and Logical Operators
- Strings
- String Indexing
- `len()`
- ASCII
- Input and Output
- Conditional Statements
- Nested Conditional Statements
- `match-case`
- Conditional Expressions
- `for` loop
- `range()`

---

# Instructions

For every problem:

- Write a complete Python program.
- Take input where mentioned.
- Use a `for` loop.
- Do not use concepts that have not been taught yet.
- Read the test case carefully.
- Match the expected output exactly.

> **Important:** Unless explicitly mentioned, do not use `while` loops, lists, functions, or advanced Python features.
