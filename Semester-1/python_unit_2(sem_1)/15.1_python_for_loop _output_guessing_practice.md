# Python For Loop — Complete Output Guessing Practice

## Objective

This practice set is designed for students who have already learned:

- Variables
- Data Types
- Type Casting
- Numbers and Arithmetic Operators
- Assignment Operators
- Comparison Operators
- Boolean and Logical Expressions
- Strings
- String Indexing
- String `split()`
- Input and Output
- Conditional Statements
- Nested Conditional Statements
- `match-case`
- Conditional Expressions
- `for` loop
- `range()`

---

# Instructions

For every question:

1. **Do not run the program first.**
2. Identify the values generated by `range()`.
3. Identify the number of iterations.
4. Check which statements are inside and outside the loop.
5. Trace the value of the loop variable.
6. Evaluate conditions one iteration at a time.
7. Calculate expressions carefully.
8. Write the **exact output**.

For error questions:

- Identify whether the code is valid.
- If valid, determine the output.
- If the range is empty, say so.
- If there is a syntax/runtime error, identify it.
- If the code runs but gives an unintended result, identify the logical mistake.

# Output Guessing Strategy

Whenever you see a `for` loop, follow these steps:

```text
Step 1
Find the range
        ↓
Step 2
Write all values of i
        ↓
Step 3
Process one iteration
        ↓
Step 4
Check conditions
        ↓
Step 5
Evaluate expressions
        ↓
Step 6
Check match-case if present
        ↓
Step 7
Write the output
        ↓
Step 8
Check statements outside the loop
```

# Example of the Tracing Method

Given:

```python
for i in range(1, 4):

    if i % 2 == 0:
        print(i, "Even")
    else:
        print(i, "Odd")

print("Done")
```

First identify the range:

```text
i = 1
i = 2
i = 3
```

Then process:

```text
i = 1 → Odd
i = 2 → Even
i = 3 → Odd
```

Finally execute the statement outside the loop:

```text
Done
```

# Important Rules to Remember

## `range()`

```python
range(stop)
range(start, stop)
range(start, stop, step)
```

### Rules

1. Default `start` is `0`.
2. Default `step` is `1`.
3. `stop` is excluded.
4. Positive `step` moves forward.
5. Negative `step` moves backward.
6. `step = 0` is invalid.
7. A wrong direction can produce an empty range.
8. One execution of the loop body is one **iteration**.

---

# Inside vs Outside the Loop

Remember indentation.

```python
for i in range(3):
    print("Inside")

print("Outside")
```

Output structure:

```text
Inside
Inside
Inside
Outside
```

But:

```python
for i in range(3):
    print("Inside")
    print("Also Inside")

print("Outside")
```

Both indented statements repeat.
