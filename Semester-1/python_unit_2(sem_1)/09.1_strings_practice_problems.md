# Quick Revision — String Slicing

## Syntax

```python
text[start:stop:step]
```

| Part | Meaning |
|---|---|
| `start` | Starting index |
| `stop` | Ending boundary — excluded |
| `step` | Direction and jump size |

## Common Patterns

```python
text[:]       # Full string
text[::2]     # Every 2nd character
text[::-1]    # Reverse the string
text[::-2]    # Reverse with a gap
text[:5]      # Start to index 4
text[5:]      # Index 5 to the end
text[-3:]     # Last 3 characters
text[:-3]     # Everything except last 3 characters
```

## Remember

1. Positive `step` → left to right.
2. Negative `step` → right to left.
3. `stop` is always excluded.
4. `start > stop` with a positive step normally gives an empty string.
5. `start > stop` with a negative step can produce characters.
6. Out-of-range slicing boundaries normally do not produce `IndexError`.
7. `[::-1]` is a common trick to reverse a string.
