## 1. What Is Input Validation?

**Input validation** is the process of checking whether the data entered by a user follows the rules required by a program.

For example, a marks-entry program may accept marks from `0` to `100`. If the user enters `150`, the input is invalid because it is outside the allowed range.

### Valid Input

Input that follows the program's requirements.

### Invalid Input

Input that does not follow the program's requirements.

| Input | Requirement | Result |
|---|---|---|
| `75` | Marks must be from 0 to 100 | Valid |
| `100` | Marks must be from 0 to 100 | Valid |
| `-5` | Marks must be from 0 to 100 | Invalid |
| `150` | Marks must be from 0 to 100 | Invalid |

**Important:** Validity depends on the rules of the program. The value `0` may be valid for marks but invalid for age or quantity.

## 2. Basic Validation Using Conditions

A program can use `if`, `elif`, and `else` to check a value.

### Example 1: Validate a Positive Age

```python
age = int(input("Enter your age: "))

if age > 0:
    print("Valid age")
else:
    print("Invalid age")
```

If the user enters `20`, the program prints `Valid age`. If the user enters `-4`, it prints `Invalid age`.

### Example 2: Validate a Positive Quantity

```python
quantity = int(input("Enter quantity: "))

if quantity > 0:
    print("Valid quantity")
else:
    print("Quantity must be greater than zero")
```

## 3. Range Validation

**Range validation** checks whether a value is within a specified minimum and maximum.

Examples:

- Marks: `0` to `100`
- Rating: `1` to `5`
- Month number: `1` to `12`
- Age for a particular registration: `18` to `60`

### Example 3: Validate Marks

```python
marks = int(input("Enter marks: "))

if marks >= 0 and marks <= 100:
    print("Valid marks")
else:
    print("Invalid marks")
```

Both conditions must be true:

- `marks >= 0`
- `marks <= 100`

Python also supports a chained comparison:

```python
if 0 <= marks <= 100:
    print("Valid marks")
else:
    print("Invalid marks")
```

Both versions are correct.

### Example 4: Validate a Rating

```python
rating = int(input("Enter rating (1-5): "))

if 1 <= rating <= 5:
    print("Valid rating")
else:
    print("Rating must be between 1 and 5")
```

### Boundary Values

For a valid range of `0` to `100`, test these values:

| Input | Expected result |
|---:|---|
| `-1` | Invalid |
| `0` | Valid |
| `1` | Valid |
| `99` | Valid |
| `100` | Valid |
| `101` | Invalid |

Testing the limits and values immediately outside them is called **boundary value testing**. It helps reveal errors in conditions.

4. Validate an integer between `1000` and `9999`.
5. Validate a temperature between `-50` and `60`.
6. Validate a salary between `15000` and `200000`.
7. Accept passing marks only, assuming the allowed passing-score range is `35` to `100`.

## 5. Type Validation and Conversion Errors

Input received through `input()` is always a string.

```python
value = input("Enter a number: ")
```

If the user types `25`, the variable initially contains the string `"25"`, not the integer `25`.

### Valid Numeric Text Versus Invalid Numeric Text

- `"25"` can be converted to an integer.
- `"-25"` can be converted to an integer.
- `"3.5"` cannot be converted using `int()`.
- `"hello"` cannot be converted using `int()`.

A conversion such as `int("hello")` raises a `ValueError`.

### Using `isdigit()` for Simple Digit-Only Input

```python
value = input("Enter a positive whole number: ")

if value.isdigit():
    number = int(value)
    print("Number accepted:", number)
else:
    print("Enter digits only")
```

**Limitation:** `isdigit()` does not accept negative signs or decimal points. For example, `"-5"` and `"3.5"` return `False`. It is suitable for simple digit-only inputs, not every numeric format.

### Handling Conversion Errors with `try` and `except`

```python
try:
    age = int(input("Enter your age: "))
    print("Age entered:", age)
except ValueError:
    print("Please enter a valid integer")
```

The `try` block contains code that may fail. If integer conversion raises `ValueError`, the `except` block handles it instead of letting the program terminate with that error.

**Remember the difference:**

- Conversion checks whether text can be converted to a data type.
- Validation checks whether the resulting value follows the program's rules.

For example, `"150"` converts to an integer successfully but is invalid if marks must be between `0` and `100`.

## 6. Conditional Validation

**Conditional validation** means that a validation rule depends on another value or condition.

### Example 7: Validate a Withdrawal Amount

Assume the available balance is ₹5,000. The withdrawal amount must be positive and must not exceed the balance.

```python
balance = 5000
amount = int(input("Enter withdrawal amount: "))

if amount <= 0:
    print("Amount must be greater than zero")
elif amount > balance:
    print("Insufficient balance")
else:
    balance = balance - amount
    print("Withdrawal successful")
    print("Remaining balance:", balance)
```

This example demonstrates multiple validation rules and different error messages.

### Example 8: Validate a Discount Code Only When Needed

```python
choice = input("Apply discount? (yes/no): ").strip().lower()

if choice == "yes":
    code = input("Enter discount code: ")

    if code == "SAVE10":
        print("Discount applied")
    else:
        print("Invalid discount code")

elif choice == "no":
    print("No discount applied")
else:
    print("Please enter yes or no")
```

The program asks for a discount code only when the user chooses `yes`. Calling `lower()` allows inputs such as `YES` and `Yes` to be treated as `yes`.

### Practice

2. Give free delivery when an order amount is at least ₹500.
3. Check a password only when the username is correct.
4. Validate a discount code only if the customer chooses to apply a discount.
5. Accept a scholarship application only if marks are at least `85` and attendance is at least `75`, assuming both are percentages.
6. Reject a withdrawal if the amount is non-positive or exceeds the available balance.

## 8. String Format Validation

String format validation checks whether text follows a simple pattern or structure.

### Example 10: Validate a Four-Digit PIN

```python
pin = input("Enter a 4-digit PIN: ")

if len(pin) == 4 and pin.isdigit():
    print("PIN format is valid")
else:
    print("PIN must contain exactly four digits")
```

Why use a string instead of converting the PIN to an integer? A PIN such as `"0123"` has four digits, but converting it to an integer removes the leading zero.

This example checks the PIN's format only. It does not check whether the PIN is the correct secret PIN.

### Example 11: Validate a Password Length

```python
password = input("Enter password: ")

if len(password) >= 8:
    print("Password length is valid")
else:
    print("Password must contain at least 8 characters")
```

This checks length only. A real application may require additional password rules.

## 9. Useful String Validation Methods

Python provides string methods that can validate the characters in a string. These methods return either `True` or `False`.

### 9.1 `isalpha()`

Returns `True` if the string is non-empty and all its characters are alphabetic letters.

```python
print("Sumit".isalpha())       # True
print("HelloWorld".isalpha())  # True
print("Sumit Kumar".isalpha()) # False: contains a space
print("Sumit123".isalpha())    # False: contains digits
print("".isalpha())           # False: empty string
```

Use it when an input should contain letters only. Note that alphabetic characters from many languages can also be accepted; it is not limited to `A-Z` and `a-z`.

### 9.2 `isnumeric()`

Returns `True` if the string is non-empty and all its characters are numeric characters.

```python
print("12345".isnumeric())  # True
print("2026".isnumeric())  # True
print("12.5".isnumeric())  # False: contains a decimal point
print("-25".isnumeric())   # False: contains a minus sign
print("12A".isnumeric())   # False
print("".isnumeric())      # False
```

**Important:** `isnumeric()` checks characters; it does not check whether a string is a valid Python number in every numeric format. Some Unicode characters, such as certain fraction or superscript characters, can be considered numeric.

For ordinary digit-only input, `isdigit()` is often more familiar, but it also accepts some Unicode digit characters. If a requirement specifically allows only ASCII digits `0` through `9`, use a check such as `all("0" <= ch <= "9" for ch in value)` or a regular expression such as `[0-9]+`.

### 9.3 `isalnum()`

Returns `True` if the string is non-empty and every character is either alphabetic or numeric. It does not allow spaces or punctuation.

```python
print("Sumit123".isalnum())  # True
print("Python".isalnum())   # True
print("12345".isalnum())    # True
print("Sumit Kumar".isalnum())  # False: contains a space
print("user_name".isalnum())    # False: contains underscore
print("user-123".isalnum())     # False: contains hyphen
print("".isalnum())             # False
```

### 9.4 Compare the Methods

| Method | What it checks | Example that returns `True` |
|---|---|---|
| `isalpha()` | Letters only | `"Python"` |
| `isnumeric()` | Numeric characters only | `"12345"` |
| `isalnum()` | Letters and/or numeric characters | `"Python123"` |
| `isdigit()` | Digit characters | `"12345"` |
| `isspace()` | Whitespace characters only | `"   "` |

All these methods return `False` for an empty string.

### Example 18: Validate a Name

This example allows letters and spaces, but rejects blank input and names containing digits. It is a simple classroom rule, not a complete rule for every person's name.

```python
name = input("Enter your name: ").strip()

if name == "":
    print("Name cannot be empty")
elif all(part.isalpha() for part in name.split()):
    print("Name format accepted")
else:
    print("Use letters and spaces only")
```

### Example 19: Validate a Username Using String Methods

```python
username = input("Enter username: ")

if username.isalnum() and len(username) >= 5:
    print("Username accepted")
else:
    print("Username must contain at least 5 letters/digits")
```

This rule does not allow underscores. Use regular expressions when a format needs more specific rules.

## 10. Regular Expressions for Input Validation

A **regular expression (regex)** is a pattern used to search for or validate text. Python provides regular-expression support through the built-in `re` module.

```python
import re
```

Regex is useful when input must follow a specific format, such as a PIN, username, phone number, or simple email-like structure.

### 10.1 The Most Important `re` Functions

| Function | Purpose |
|---|---|
| `re.fullmatch(pattern, text)` | Checks whether the entire string matches the pattern |
| `re.match(pattern, text)` | Checks for a match at the beginning of the string |
| `re.search(pattern, text)` | Finds a match anywhere in the string |
| `re.findall(pattern, text)` | Returns all non-overlapping matches |
| `re.sub(pattern, replacement, text)` | Replaces matching parts of a string |

**For input validation, prefer `re.fullmatch()`** because the whole input must follow the required format. `re.search()` may find a valid-looking part inside an otherwise invalid input.

### 10.2 Ready-to-Use Regex Patterns

Students can use the following patterns as starting points for common input-validation tasks. You do not need to memorize or understand every symbol immediately; the patterns can be explained gradually in class.

**Important:** These patterns check the input format only. A matching result does not prove that an email address exists, a phone number is active, or a password is secure.

#### A. Four-Digit PIN

```python
import re

pin = input("Enter a 4-digit PIN: ")

if re.fullmatch(r"[0-9]{4}", pin):
    print("Valid PIN format")
else:
    print("PIN must contain exactly four digits")
```

Examples accepted: `1234`, `0123`  
Examples rejected: `123`, `12345`, `12a4`

Keep a PIN as a string so that a leading zero is preserved.

#### B. Indian Mobile Number (10 Digits)

This classroom pattern accepts 10 digits, with the first digit from 6 to 9.

```python
import re

mobile = input("Enter mobile number: ")

if re.fullmatch(r"[6-9][0-9]{9}", mobile):
    print("Mobile number format is valid")
else:
    print("Enter 10 digits starting with 6, 7, 8, or 9")
```

This checks the format only; it does not verify whether the number is active or assigned.

#### C. Email Address (Simple Format)

```python
import re

email = input("Enter email address: ").strip()
pattern = r"[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}"

if re.fullmatch(pattern, email):
    print("Email format looks valid")
else:
    print("Invalid email format")
```

Examples that match this pattern: `student@example.com`, `first.last@college.in`.

This is a useful beginner-level pattern, not a complete implementation of every email-address rule. A match cannot confirm that the address exists or can receive messages.

#### D. Password (Basic Classroom Rules)

Requirement: at least 8 characters, including at least one uppercase letter, one lowercase letter, and one digit.

```python
import re

password = input("Create password: ")
pattern = r"(?=.*[A-Z])(?=.*[a-z])(?=.*[0-9]).{8,}"

if re.fullmatch(pattern, password):
    print("Password matches the basic rules")
else:
    print("Use at least 8 characters with uppercase, lowercase, and a digit")
```

These are basic classroom rules only. Real applications need a broader security approach, and a regex match does not by itself mean a password is secure.

#### E. Date of Birth (DOB) Format: DD-MM-YYYY

This first pattern checks the format only: two digits, a hyphen, two digits, a hyphen, and four digits.

```python
import re

dob = input("Enter DOB (DD-MM-YYYY): ")

if re.fullmatch(r"[0-9]{2}-[0-9]{2}-[0-9]{4}", dob):
    print("DOB format is correct")
else:
    print("Use DD-MM-YYYY format")
```

**Note:** Format checking alone would accept impossible dates such as `39-19-2026`. To check whether the date actually exists, use `datetime` as well:

```python
from datetime import datetime

dob = input("Enter DOB (DD-MM-YYYY): ")

try:
    datetime.strptime(dob, "%d-%m-%Y")
    print("Valid date")
except ValueError:
    print("Invalid date. Use DD-MM-YYYY")
```

#### F. Username (5–15 Characters)

Rule: starts with an English letter and then contains only English letters, digits, or underscores.

```python
import re

username = input("Enter username: ")
pattern = r"[A-Za-z][A-Za-z0-9_]{4,14}"

if re.fullmatch(pattern, username):
    print("Valid username format")
else:
    print("Username must be 5-15 characters and start with a letter")
```

#### G. Only English Letters

```python
import re

name = input("Enter a name: ")

if re.fullmatch(r"[A-Za-z]+", name):
    print("Letters only")
else:
    print("Use English letters only, without spaces")
```

This version does not accept spaces, hyphens, or apostrophes. For full names, a different rule may be needed.

#### H. Only Digits

```python
import re

value = input("Enter digits only: ")

if re.fullmatch(r"[0-9]+", value):
    print("Digits accepted")
else:
    print("Enter digits only")
```

This accepts one or more digits and rejects an empty input.

#### I. Postal PIN Code (India, 6 Digits)

```python
import re

pin_code = input("Enter 6-digit postal PIN code: ")

if re.fullmatch(r"[1-9][0-9]{5}", pin_code):
    print("PIN code format is valid")
else:
    print("Enter a 6-digit PIN code that does not start with 0")
```

This checks the basic six-digit format only; it does not verify whether the PIN code is assigned.

#### J. Time in 24-Hour Format (HH:MM)

```python
import re

time_text = input("Enter time (HH:MM): ")

if re.fullmatch(r"([01][0-9]|2[0-3]):[0-5][0-9]", time_text):
    print("Time format is valid")
else:
    print("Use a valid 24-hour time such as 09:30 or 18:45")
```

#### K. Website Address (Simple HTTP/HTTPS Format)

```python
import re

website = input("Enter website address: ").strip()
pattern = r"https?://[A-Za-z0-9.-]+\.[A-Za-z]{2,}(/\S*)?"

if re.fullmatch(pattern, website):
    print("Website address format looks valid")
else:
    print("Enter an address starting with http:// or https://")
```

This is a simple example pattern, not a complete validator for all valid website addresses.

### 10.3 Using Regex for Validation

For most input-validation tasks in these notes, use `re.fullmatch()` so that the **whole input** must follow the pattern.

```python
import re

print(re.fullmatch(r"[0-9]+", "12345") is not None)  # True
print(re.fullmatch(r"[0-9]+", "12abc") is not None)  # False
```

`re.search()` is useful when you want to find a matching part anywhere in a string, rather than validate the whole input.

### Notes for Students

- Start with the ready-made patterns in this section and test them with both valid and invalid inputs.
- You do not need to memorize every regex pattern.
- If you need another pattern, you can search online for a suitable regex, then test and understand it before using it. For example, search for `Python regex for email validation` or `Python regex for date validation`.
- Regex patterns found online may have limitations. Choose one that fits the exact requirements of your program.

## 11. Repeated Input Until Valid

So far, an invalid value may produce an error message and then the program ends. A better user experience is to ask again until a valid value is entered.

A `while` loop is useful for this.

### Example 12: Keep Asking for Valid Marks

```python
marks = int(input("Enter marks (0-100): "))

while marks < 0 or marks > 100:
    print("Invalid marks. Try again.")
    marks = int(input("Enter marks (0-100): "))

print("Accepted marks:", marks)
```

The loop continues while marks are outside the allowed range. When the user enters a value between `0` and `100`, the loop ends.

**Common mistake:** Forgetting to take input again inside the loop can create an infinite loop because the value never changes.

### Example 13: Keep Asking for a Rating

```python
rating = int(input("Enter rating (1-5): "))

while rating < 1 or rating > 5:
    print("Invalid rating")
    rating = int(input("Enter rating (1-5): "))

print("Your rating is:", rating)
```

1. Keep asking until the user enters a positive number.
2. Keep asking until marks are between `0` and `100`.
3. Keep asking until a month number is between `1` and `12`.
4. Keep asking until the user enters a rating between `1` and `5`.
5. Keep asking until the user enters a password of at least eight characters.
6. Keep asking until the user enters a four-digit PIN.

The examples in this section assume the user enters the expected data type. The next section handles incorrect data types too.

## 12. Repeated Input with Error Handling

A robust validation loop should handle both conversion errors and invalid values.

### Example 14: Validate an Age

Requirements:

- The input must be an integer.
- The age must be greater than zero.
- The program must ask again if the input is invalid.

```python
while True:
    try:
        age = int(input("Enter your age: "))

        if age > 0:
            print("Valid age:", age)
            break
        else:
            print("Age must be greater than zero")

    except ValueError:
        print("Please enter a valid integer")
```

### How It Works

1. `while True` starts a loop that continues until it is stopped.
2. `try` attempts to convert the input into an integer.
3. If conversion fails, `except ValueError` displays an error message.
4. If conversion succeeds, the program checks whether the age is positive.
5. `break` exits the loop when a valid age is entered.

Example interaction:

```text
Enter your age: hello
Please enter a valid integer
Enter your age: -5
Age must be greater than zero
Enter your age: 21
Valid age: 21
```

### Example 15: Validate Marks Completely

```python
while True:
    try:
        marks = int(input("Enter marks (0-100): "))

        if 0 <= marks <= 100:
            print("Marks accepted:", marks)
            break
        else:
            print("Marks must be between 0 and 100")

    except ValueError:
        print("Please enter an integer")
```

This program handles both:
- Non-integer input, such as `hello`.
- Out-of-range integers, such as `150` or `-10`.

### Practice

1. Keep asking for age until the user enters a positive integer.
2. Keep asking for marks until the user enters an integer between `0` and `100`.
3. Keep asking for a positive price. Handle non-numeric input.
4. Keep asking for a rating until an integer from `1` to `5` is entered.
5. Keep asking for a quantity until a positive integer is entered.

## 13. Limited Number of Attempts

Some programs should not allow unlimited attempts. For example, a simple PIN demo may allow three attempts.

### Example 16: Allow Three PIN Attempts

```python
correct_pin = "2468"
attempts = 0
max_attempts = 3

while attempts < max_attempts:
    pin = input("Enter PIN: ")
    attempts += 1

    if pin == correct_pin:
        print("Access granted")
        break
    else:
        print("Incorrect PIN")

if attempts == max_attempts and pin != correct_pin:
    print("Maximum attempts reached")
```

The program allows at most three attempts. It uses a counter to track how many attempts have been made.

**Note:** This is a classroom demonstration, not a secure authentication system.

## 14. Cross-Field Validation

Cross-field validation checks whether two or more inputs are consistent with each other.

### Example 17: Confirm a Password

```python
password = input("Create password: ")
confirm_password = input("Confirm password: ")

if password == "":
    print("Password cannot be empty")
elif len(password) < 8:
    print("Password must contain at least 8 characters")
elif password != confirm_password:
    print("Passwords do not match")
else:
    print("Password accepted")
```

The program checks the fields in order:

1. The password must not be empty.
2. The password must have at least eight characters.
3. The confirmation must match the original password.

## 15. Common Mistakes

### Mistake 1: Incorrect range condition

Incorrect:

```python
if marks < 0 and marks > 100:
    print("Invalid marks")
```

A number cannot be less than `0` and greater than `100` at the same time. Use `or`:

```python
if marks < 0 or marks > 100:
    print("Invalid marks")
```

### Mistake 2: Forgetting to update the value inside a loop

Incorrect:

```python
marks = int(input("Enter marks: "))

while marks < 0 or marks > 100:
    print("Invalid marks")
```

The value never changes inside the loop, so an invalid value can cause an infinite loop.

### Mistake 3: Converting before handling possible errors

```python
age = int(input("Enter age: "))
```

This can raise `ValueError` if the user enters text that is not an integer. Use `try/except` when such input must be handled gracefully.

### Mistake 4: Checking only one rule

A four-digit PIN must contain exactly four digits, not merely four characters. Use both `len(pin) == 4` and `pin.isdigit()`.

### Mistake 5: Forgetting whitespace

A name containing only spaces should usually be treated as empty. Use `strip()` before checking whether the string is empty.

## 16. Validation Checklist

Before accepting input, ask:

1. Is the input required, or can it be empty?
2. Can the input be converted to the required data type?
3. Is the value within the permitted range?
4. Does the value follow the required format?
5. Does its validity depend on another input?
6. Should the program ask again after invalid input?
7. Should the number of attempts be limited?
8. Have boundary values and invalid cases been tested?

Not every program needs all these checks. Choose rules based on the problem requirements.

Ask for marks and accept only an integer between `0` and `100`. Repeat the prompt until valid input is entered. Handle non-integer input.

### Problem 2: Product Quantity

Ask for a positive integer quantity. Reject text, zero, and negative numbers. Repeat until valid.

### Problem 3: PIN Validation

Ask for a four-digit PIN. It must contain exactly four digits, including possible leading zeros. Allow a maximum of three attempts.

### Problem 4: Registration Form

Ask for a name, age, and password. Apply these rules:

- Name cannot be empty or contain only spaces.
- Age must be a positive integer.
- Password must contain at least eight characters.

Display a suitable message for each invalid field.

### Problem 5: Bank Withdrawal

Start with a balance of ₹10,000. Ask for a withdrawal amount. The amount must be a positive integer and must not exceed the balance. Handle non-integer input and repeat until a valid withdrawal is entered. Then display the remaining balance.

### Problem 6: Password Confirmation

Ask for a password and confirmation password. The password must contain at least eight characters, and both entries must match. Display a specific error message for each failed rule.

### Problem 7: Percentage Entry

Ask the user to enter a percentage. Handle non-numeric input and reject values outside `0` to `100`. Repeat until valid input is entered. Decide whether to support integer percentages only or decimal percentages, and implement that requirement consistently.

### Problem 8: Limited Attempts

Set a secret number in the program. Allow the user five attempts to enter a number within a specified valid range. Validate the input type and range before comparing it with the secret number.

## Summary

Input validation makes programs more reliable by ensuring that data follows the rules expected by the program.

The main concepts are:

- Valid and invalid input
- Type and range validation
- Empty input validation
- Conditional and multiple-condition validation
- String format validation
- Repeated input using `while`
- Conversion error handling using `try/except`
- Boundary value testing
- Limited attempts
- Cross-field validation

**Recommended learning order:** Start with conditions, then range checks, empty input, conditional validation, repeated input, and finally `try/except` and combined problems.
