# Quick Tracing Rule

For every outer-loop iteration, mentally follow this order:

```text
Outer loop starts
        ↓
Execute normal statements
        ↓
Enter nested loop
        ↓
Complete nested loop
        ↓
Execute sibling loop (if present)
        ↓
Execute remaining statements
        ↓
Next outer iteration
```

For string iteration:

```python
for ch in "ABC":
```

means:

```text
ch = A
ch = B
ch = C
```

For nested loops, remember:

> **One outer iteration completes ALL inner iterations before the outer loop moves to its next value.**
