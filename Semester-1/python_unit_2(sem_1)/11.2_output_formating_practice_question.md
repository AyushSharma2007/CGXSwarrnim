# Python Input & Output

## Instructions

- Take **all variable values from the user using `input()`**.
- Do not directly assign the given sample values to variables.
- Use suitable variable names.
- Use only the concepts covered so far:
  - `input()`
  - `print()`
  - Escape sequences: `\n`, `\t`, `\'`, `\"`, `\\`
  - f-strings
  - Raw strings
  - `sep`
  - `end`
- Do not use `if`, `elif`, `else`, loops, lists, or other advanced concepts.

---

## Q1. Student ID Card

Ask the user for:

- Name
- Roll number
- Course
- City

Display the information like a small student ID card.

### Sample Input

```text
Enter name: Rahul
Enter roll number: 27
Enter course: B.Tech CSE
Enter city: Ahmedabad
```

### Expected Output

```text
================================
        STUDENT ID CARD
================================
Name       : Rahul
Roll No.   : 27
Course     : B.Tech CSE
City       : Ahmedabad
================================
```

**Requirement:** Use an f-string, `\n`, and `\t` to make the output neat.

## Q3. File Location Display

Ask the user for:

- Drive letter
- Folder name
- File name

Create and display a Windows-style file path.

### Sample Input

```text
Enter drive: C:
Enter folder: Python Programs
Enter file name: calculator.py
```

### Expected Output

```text
File Location
-------------
C:\Python Programs\calculator.py

File: calculator.py
Folder: Python Programs
```

**Requirement:** Use an f-string and handle the backslash `\` correctly. Use the concept of a **raw string** where appropriate.

## Q5. Student Information Card – Challenge

Ask the user for:

- Name
- Age
- City
- College

Create a neat student information card.

### Sample Input

```text
Enter name: Karan
Enter age: 18
Enter city: Surat
Enter college: ABC Engineering College
```

### Expected Output

```text
========================================
          STUDENT INFORMATION
========================================
Name    | Age    | City
----------------------------------------
Karan   | 18     | Surat

College : ABC Engineering College
========================================
        Welcome to Python!
========================================
```

### Challenge Requirements

Your program must use:

- `input()` for **all values**
- At least one **f-string**
- `\t`
- `sep`
- `end`
- At least one `\n`

Try to make the output as close as possible to the expected output.

**Hint:** You can combine multiple values in one `print()` statement and use `sep` to control how they are separated.
