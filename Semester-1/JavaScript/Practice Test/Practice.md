

## Mock Test Paper 1 (Total Marks: 40)

### Section A: Short Answer Questions (All Compulsory - 8 Marks)
* **Q.1 (2 Marks):** Explain why JavaScript is called a high-level and dynamically typed language.
* **Q.2 (2 Marks):** Explain the logical operators `&&`, `||`, and `!` with a simple example each.
* **Q.3 (2 Marks):** Explain implicit and explicit type coercion in JavaScript. Provide clear examples of how `5 == "5"` and `5 === "5"` behave differently due to type coercion.
* **Q.4 (2 Marks):** Why do `null == undefined` and `null === undefined` give different boolean results?

### Section B: Conceptual & Descriptive Questions (Attempt Any 3 out of 4 - 18 Marks)
* **Q.5 (6 Marks):** Differentiate thoroughly between `var`, `let`, and `const` using a comparison table.
* **Q.6 (6 Marks):** Explain the three pillars of front-end web development (HTML, CSS, JavaScript) and define what front-end and backend development mean.
* **Q.7 (6 Marks):** Compare `if...else if...else` and `switch` statements. Under what conditions is a `switch` statement preferred over multiple `else if` branches?
* **Q.8 (6 Marks):** Give the syntax of a nested ternary operator and provide a one-line example.

### Section C: Programming & Practical Implementation (Attempt Any 2 out of 3 - 14 Marks)
* **Q.9 (7 Marks):** Write a JavaScript program using an `if-else if-else` statement to categorize a person's age group (Child < 13, Teenager < 20, Adult < 60, Senior >= 60).
* **Q.10 (7 Marks):** Write a JavaScript program that calculates the area of a square given a side length variable (`side = 5`) and the perimeter of a circle given a radius variable (`radius = 7`), printing the computed values and their data types using `typeof`.
* **Q.11 (7 Marks):** Write a JavaScript program to:
  * **a.** Print 5 stars in a single line.
  * **b.** Print 5 stars in different lines using 2 different `for` loops.

## Mock Test Paper 2 (Total Marks: 40)

### Section A: Short Answer Questions (All Compulsory - 8 Marks)
* **Q.1 (2 Marks):** What is the role of Node.js, and how does it help JavaScript beyond frontend web development?
* **Q.2 (2 Marks):** What is the purpose of the `typeof` operator? Give one example.
* **Q.3 (2 Marks):** State the difference between loose inequality (`!=`) and strict inequality (`!==`).
* **Q.4 (2 Marks):** State one difference between `while` and `do...while` loops.

### Section B: Conceptual & Descriptive Questions (Attempt Any 3 out of 4 - 18 Marks)
* **Q.5 (6 Marks):** Explain the roles of HTML, CSS, and JavaScript in front-end web development. Differentiate between frontend and backend development with one example of each.
* **Q.6 (6 Marks):** List all Arithmetic operators in JavaScript. Explain division (`/`), modulus (`%`), and exponentiation (`**`) with one example or edge case each.
* **Q.7 (6 Marks):** Explain the syntax and execution flow of a nested `if` statement. Provide a programming example, such as checking username and password.
* **Q.8 (6 Marks):** Compare `for`, `while`, and `do...while` loops. Specify when each looping structure is best suited for a programming task.

### Section C: Programming & Practical Implementation (Attempt Any 2 out of 3 - 14 Marks)
* **Q.9 (7 Marks):** Write a JavaScript program using a `while` loop to print all even numbers from 2 to 20, and a `do...while` loop to print all odd numbers from 20 down to 1. Also demonstrate how a `do...while` loop executes at least one time even if its condition is false.
* **Q.10 (7 Marks):** Write a JavaScript program using a `for` loop to print numbers from 1 to 50 which are divisible by both 3 and 5, and the multiplication table of 27.
* **Q.11 (7 Marks):** Write a JavaScript program using a `switch` statement that acts as a simple calculator with cases for `+`, `-`, `*`, and `/`, including a `default` case for invalid inputs.
