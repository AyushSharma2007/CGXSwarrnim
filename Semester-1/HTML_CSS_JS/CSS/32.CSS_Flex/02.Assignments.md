## Question 3 — Fix the flexible dashboard columns 

[Gentelella — The free admin dashboard template, redesigned for 2026](https://images.openai.com/static-rsc-4/hQKnXOc8ILJjpVvxQxeI7dww1NsfJLZ43A0ja_G2WiZnaMTJalxK8Ocr4udr5dy-z1TEJss1OKFI_nceG9NF8vXpL3oHkvBEz0a-M6Sp2-rYZPG2RdmXFip2yPsW8pCpllo4B_MLd1NgrfAS-clB_Pz7exA0oH_15kjhc_-d7r0?purpose=inline)

Objective: Practice `flex-grow`, `flex-shrink`, `flex-basis`, `flex`, and `align-self`.

A dashboard has a sidebar, main content area, and right-hand activity panel. The sidebar should remain approximately 200px wide, the main content should take the remaining space, and the activity panel should be about 250px wide.

The main content should be allowed to grow and shrink, while the other two panels should maintain their intended widths as much as possible.

```

  <main class="main-content">
    <h2>Dashboard Overview</h2>
    <p>This is the main content area.</p>

      responds when the available space changes.
    </p>
  </main>

  <aside class="activity-panel">
    <h3>Recent Activity</h3>
    <p>New user registered</p>
    <p>Order completed</p>
  </aside>
</div>
```

Broken CSS

```
.dashboard {
  display: flex;
  width: 1000px;
  height: 400px;
  flex-direction: column;
  gap: 15px;
  align-items: center;
}

.sidebar {
  flex: 1 1 200px;
  width: 200px;
  background: #ddd;

  flex: 1 1 250px;

  background: #eee;

  padding: 15px;

```

Your tasks

1. Place all three panels horizontally.
2. Keep the sidebar at approximately 200px and the activity panel at approximately 250px.
3. Let the main content take the remaining width.
4. Correct the `flex` values so the main panel can grow and shrink appropriately.
5. Prevent the main content from forcing the entire layout to overflow because of long content.
6. Use `align-self` to make the activity panel align to the start of the cross axis, even if the parent alignment is changed to `stretch`.
7. Test your layout at 1000px and 700px container widths. Explain the difference you observe in the panels' sizes through code comments.
8. Use `flex-basis` to establish the intended starting sizes of the panels.

Expected result: A three-column dashboard where the center panel is flexible and the side panels retain their preferred widths when space allows.
